 Retail Orders Insights Portfolio

 📊 Project Overview

This project analyzes retail order data using Microsoft Excel to understand sales performance, customer behavior, regional revenue, and product-category performance.

The project follows an end-to-end analytics workflow, from raw data cleaning to statistical analysis, pivot tables, and dashboard reporting.

It was created as part of my Business Analytics portfolio to demonstrate practical Excel and data analysis skills.

 🎯 Project Objectives

* Clean and validate retail order data.
* Calculate important business KPIs.
* Analyze revenue by region and customer segment.
* Study order value distribution and outliers.
* Use descriptive statistics to understand sales patterns.
* Build pivot tables and an interactive Excel dashboard.
* Convert raw data into actionable business insights.

💡 Key Insights

The current workbook reports the following findings:

1. Average order value is approximately $890.27, while the median is approximately $473.33.
2. Order values are right-skewed, with some large orders increasing the average.
3. The reported sample standard deviation is approximately $1,048.81.
4. Eight high-value outlier orders are identified above approximately $2,922.95.
5. Central is reported as the highest-revenue region.
6. Corporate customers have the highest reported average order value among the listed segments.

These findings are descriptive and based on the current workbook.
